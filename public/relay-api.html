Relay API

One public WebSocket endpoint that moves game packets between browsers, so players on different networks can host and join without opening a port. Free to use by anyone, with no account.

wss://aetheris.win/eos-relay · alias wss://aetheris.win/relay

The relay is transparent: it forwards binary frames between sockets and keeps a directory of the servers each player advertises. It never parses a payload, so any game can use it as long as it speaks the framing below (it is the relay of the Rexcomp web ports, e.g. Meccha Chameleon).

Options

Everything is configured on the connection URL. Every value is clamped, so a URL cannot raise the limits.

ParameterDefaultMeaning
roomempty (public)A private relay: up to 32 letters, digits, _ or -. Players in different rooms never see each other's servers and packets never cross. Share the code with friends to keep a game off the public list.
maxSessions8How many servers this one connection may advertise (1–8).
idle65Seconds without a message or pong before the socket is dropped (20–300).
 
wss://aetheris.win/eos-relay?room=FRIENDS
wss://aetheris.win/eos-relay?room=FRIENDS&maxSessions=2&idle=120

Frames

Binary WebSocket messages. The first byte is the kind, integers are big-endian. Ids are 32 printable ASCII characters; a session id is at most 64 characters and its record at most 4 KB (the relay treats the record as opaque bytes).

Client → relayRelay → client
H puid[32]
Say hello. Required before anything else.		 P src[32] payload
A packet from another player.
P dst[32] payload
Send a packet to that player.		 G puid[32]
That player left, or was never connected.
S n:u16 sid record
Advertise a hosted server.		 R qid:u32 n:u16 (len:u32 record)*
Reply to the search with this id.
D n:u16 sid
Withdraw one of your servers.		 Sockets close with 1008 for a protocol or rate error, 1009 for a frame over the cap, 1013 when the relay is full, 1029 when one address has too many players.
Q qid:u32
List the servers of everyone else in your room.

Limits

LimitValue
Frame size16 KB
Rate per socket300 messages and 256 KB per second, burst 900 / 1 MB
Sockets1024 total, 48 per address
Players512 total, 32 per address
Advertised servers8 per player (fewer with maxSessions)
KeepaliveA ping every 20 s; a silent socket is dropped after idle seconds

Browser example

const ws = new WebSocket("wss://aetheris.win/eos-relay?room=FRIENDS");
ws.binaryType = "arraybuffer";

const text = (s) => new TextEncoder().encode(s);
const hello = (id) => Uint8Array.from([...text("H"), ...text(id.padEnd(32, "0").slice(0, 32))]);

ws.onopen = () => ws.send(hello("player-1"));

ws.onmessage = (event) => {
  const bytes = new Uint8Array(event.data);
  const kind = String.fromCharCode(bytes[0]);
  if (kind === "P") {
    const from = new TextDecoder().decode(bytes.subarray(1, 33));
    console.log("packet from", from, bytes.subarray(33));
  }
};

Python example

import asyncio, websockets

async def main():
    async with websockets.connect("wss://aetheris.win/eos-relay") as ws:
        await ws.send(b"H" + b"player-1".ljust(32, b"0"))
        await asyncio.sleep(2)   # a browser answers the relay's pings itself

asyncio.run(main())

Notes

  • The relay is unauthenticated: an id is whatever a client claims. Do not put secrets in a payload, and do not trust an id as an identity.
  • Any website may open a connection (it only moves packets between players), so a page served from localhost, a tunnel or another domain all work.
  • A player's servers are withdrawn the moment its socket closes, and a vanished socket is detected by the keepalive, so dead games do not pile up in search results.
  • Games with their own server browser need no join codes: they advertise with S and list with Q. A room is the code, when you want one.
  • Rexcomp ports use it directly: ?REXCOMP_RELAY=wss://aetheris.win/eos-relay, or with a room, ?REXCOMP_RELAY=wss://aetheris.win/eos-relay?room=FRIENDS.
